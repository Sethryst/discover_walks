# Icon sources

The interface icon set uses the Feather Icons and Tabler Icons visual systems.
Both projects are distributed under the MIT License. The small application-specific
water-fountain and bench compositions use the same 24×24, two-pixel stroke grammar.

- Feather Icons: https://github.com/feathericons/feather — MIT
- Tabler Icons: https://github.com/tabler/tabler-icons — MIT

Copyright remains with the respective projects and contributors.
