# Gremlin Lab repository

This repository contains two products, not one app:

- [`motherbird/`](motherbird/) — Walk & Wildlife, a vanilla JavaScript local-first PWA. Live at [sethryst.github.io/discover_walks](https://sethryst.github.io/discover_walks/).
- [`app/`](app/) — Gremlin Lab, a Python 3.12 static pack factory.

There is no first-party HTTP API. Do not put FastAPI in the PWA.

Read [`motherbird/README.md`](motherbird/README.md) for the walker-facing product and [`app/README.md`](app/README.md) for the Lab.
