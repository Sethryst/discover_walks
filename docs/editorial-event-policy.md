# Editorial event policy

Editorial listings are valid discovery sources for `category:event` records. They are not election or public-notice authorities and must never be represented as such.

An editorially sourced event may be published only when the listing supplies an explicit free claim (or the source is dedicated to free events), an event date/time, a public source URL, and a precisely mapable physical location. Published records include `sourceTier: "editorial"`, `isFree: true`, the listing URL, and `freshnessExpiresAt`.

If a listing links to an organizer or government page, preserve it as `officialUrl`. If it does not, the editorial listing itself remains the action URL and is identified as the source. User reports are application-owned: they can hide a local event pending review, but do not mutate a Gremlin Lab release or send personal data to it.
